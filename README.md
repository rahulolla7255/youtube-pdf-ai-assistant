# 🤖 YouTube + PDF RAG Chatbot

A Generative AI chatbot that answers questions from **PDF documents and YouTube video transcripts** using **Retrieval Augmented Generation (RAG)**.

The application allows users to upload PDFs, add YouTube videos, ask questions, and get AI-generated answers based on the provided knowledge sources.

---

## 🚀 Features

- 📄 Ask questions from PDF documents
- ▶️ Extract information from YouTube video transcripts
- 🔍 Semantic search using FAISS Vector Database
- 🧠 RAG-based question answering
- 🤖 LLM-powered responses using Groq Llama model
- 🎤 Voice input support
- 🔊 Text-to-speech answer generation
- 📚 Multiple document support
- 🌐 Streamlit web interface
